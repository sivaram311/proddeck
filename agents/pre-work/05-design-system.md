# 05 - Design System

**Status:** GO 2026-07-14 (extends 2026-07-13)  
**Project:** ProdDeck

## Unchanged

Deep ink + electric lime; Syne + DM Sans; Realme 360×800; brand **ProdDeck** hero on first viewport.

## First viewport (catalog default)

1. Brand ProdDeck  
2. One supporting sentence  
3. App grid  
4. Logout  
5. Compact module switch (Catalog | Helpdesk | Scene) — does not overpower brand

## Scene stub

- Small atmosphere panel only when Scene selected — not a full-bleed AgentVerse office.
- No purple/glow AI cliché; stay on ink/steel/lime tokens.

## Helpdesk

- Inline list + create form; no dashboard card explosion.
- Lime accent for primary submit only.
